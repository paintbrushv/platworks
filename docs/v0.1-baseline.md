# v0.1 catalog baseline

Verified 2026-10-03 against GitHub's unauthenticated public repository API.
The [snapshot](catalog-evidence.json) records repository URL, visibility,
description, license, and default branch for all nine catalogued components.
The catalog now correctly exposes agent, costmodel, submarket atlas, and
supply/demand as public. Supply/demand is MIT; the umbrella remains Apache-2.0.

Before a release, run the catalog verifier against the current public API:

```bash
PYTHONPATH=src python scripts/verify_catalog.py --live
```

Without `--live`, it checks the committed evidence snapshot offline. Drift
fails the check; update the evidence and catalog together after review.
There are no runtime network calls in the catalog.

Local validation on 2026-10-03: 86 affected catalog, CLI, documentation,
landing-page, demo, and MCP tests passed, including real stdio round trips.
The lint suite and isolated umbrella `pip check` passed. Python was 3.14.4;
the hosted Python 3.11/3.12 jobs remain pending. The full financial-wrapper
suite and the complete analysis dependency set are separate release gates.

The stack's starting source pins are recorded in `plat-harness`'s
`release/v0.1-baseline.json`. They are a development baseline, not approval
of a release candidate. Public visibility does not establish financial
acceptance or host compatibility.

Remaining work includes the authoritative engine backsolve API, exact-cent
Rust operating workflow, MCP dependency alignment, complete installed analysis
packages, local file review workflows, reference-library search, real
ChatGPT/Claude/Grok verification, and website/community rollout. Muse remains
pending external review. The existing Python operating oracle and duplicated
backsolve are still present and must be replaced before release.
